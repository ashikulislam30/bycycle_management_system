
# Bicycle Management System

A fully functional Bicycle Management System (BMS) for managing bicycle rentals, student and admin logins, maintenance mode, bicycle inventory, rental history, and user management. The system provides an interactive interface for both students and admins to perform various operations related to bicycle rentals.

## Features

- **Admin Panel**: 
  - Manage bicycles (add, update, remove).
  - View rental history.
  - Manage users (add, update, remove).
  - Toggle maintenance mode.
  - Change admin password.

- **Student Panel**:
  - Student registration and login.
  - Rent a bicycle (choose bicycle, rental duration).
  - View rental history.
  - File complaints and leave reviews.

- **Security**:
  - Password hashing for secure login.
  - Unique transaction IDs for every rental.
  - Various levels of admin control (super admin access for maintenance mode and admin management).

- **Rental Management**:
  - Bicycle rental and return.
  - Payment processing via Bkash and Nagad.
  - Track bicycle inventory and rental quantities.

- **System Settings**:
  - Maintenance mode to take the system offline for updates.
  - Admin and student login systems with unique usernames and passwords.

## Technologies Used

- **Programming Language**: C
- **Platform**: Windows (uses Sleep and system commands for UI delays and clearing screen).
- **Data Structure**: Linked lists for storing bicycles, users, rental history, and system settings.
- **Security**: Simple password hashing mechanism.
